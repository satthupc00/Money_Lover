Mondiro Mon Money Lover · tạo Firebase để đồng bộ

Miễn phí, khoảng 5 phút. Làm trên máy tính sẽ dễ hơn trên điện thoại.

Firebase là nơi lưu dữ liệu trên mạng để PC và điện thoại thấy cùng một sổ chi tiêu. Bạn chỉ cần tạo 1 lần. Nhớ dùng đúng 1 tài khoản Google từ đầu đến cuối.

  1. Tạo project

    Vào console.firebase.google.com (kiểm tra ảnh đại diện góc trên bên phải là đúng tài khoản Google).

    • Bấm Create a project (hoặc Add project).
    • Đặt tên, ví dụ mon-money-lover → Continue.
    • Tắt Google Analytics cho gọn → Create project.
    • Chờ tới khi hiện "Your new project is ready" rồi bấm Continue. Đừng đóng trang giữa chừng, project sẽ không được tạo.

  2. Bật đăng nhập bằng email

    • Menu bên trái: Build → Authentication → Get started.
    • Tab Sign-in method → chọn Email/Password → bật công tắc đầu tiên Enable → Save.

  3. Tạo nơi lưu dữ liệu (Firestore)

    • Menu bên trái: Build → Firestore Database → Create database.
    • Location: chọn asia-southeast1 (Singapore), gần Việt Nam nên nhanh hơn.
    • Chọn Start in production mode → Create.

  4. Dán quy tắc bảo mật

    Trong Firestore, mở tab Rules, xoá hết nội dung cũ, dán đoạn dưới đây rồi bấm Publish:

    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

    Nhờ đoạn này, mỗi tài khoản chỉ đọc / ghi được dữ liệu của chính mình.

  5. Lấy đoạn cấu hình cho app

    • Bấm bánh răng ⚙ cạnh Project Overview → Project settings.
    • Kéo xuống mục Your apps → bấm biểu tượng </> (Web).
    • Đặt tên app, ví dụ Mon Money Lover, không tick Firebase Hosting → Register app.
    • Copy nguyên đoạn có dạng:
    const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "mon-money-lover.firebaseapp.com",
  projectId: "mon-money-lover",
  storageBucket: "mon-money-lover.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abc123"
};

    Đoạn này không phải mật khẩu, gửi qua chat được.

  6. Đưa vào app

    Cách nhanh nhất: gửi đoạn trên cho Claude. Claude sẽ gắn sẵn vào bản app tiếp theo, bạn không phải dán trên từng máy.

    Hoặc tự dán: trong app vào Cài đặt → Kết nối Firebase → dán → Lưu và mở lại app. Làm trên cả PC và điện thoại.

  7. Đăng nhập trong app

    • Vào Cài đặt, nhập email + mật khẩu (từ 6 ký tự).
    • Máy đầu tiên: bấm Tạo tài khoản. Dữ liệu đang có trên máy đó sẽ tự đưa lên tài khoản.
    • Máy thứ hai: bấm Đăng nhập với cùng email, mật khẩu.

    Xong: đầu app hiện "Đã đồng bộ", PC và điện thoại thấy cùng dữ liệu.

Nếu project biến mất: kiểm tra lại đúng tài khoản Google, hoặc xem ở trang project chờ xoá (khôi phục được trong 30 ngày).
